# MCQ-0105 主控USART2接入MiniMCProto协议解析与版本查询响应

## 目标

为彻底消除物理串口上的迪文屏（DWIN DGUS）噪声并实现真实双向闭环，在 `mcu-p3/motion-controller-mcu`（AT32F435VGT7）固件中：
1. 关停/旁路 USART2 原有的迪文彩屏定时发送逻辑（消除 11KB/s 的 `5A A5 07 82` 噪声）；
2. 接入 MiniMCProto v2.0 轻量解析器，挂载至 USART2 接收链路；
3. 实现对 `CMD_VERSION_GET (0x0003)` 指令的处理，格式化合法的 MiniMCProto 应答帧（包含固件版本 `V1.9.1`、时间戳、Git Commit `14b8057`）并通过 USART2 回传；
4. 编译固件 `make -C mcu-p3/motion-controller-mcu pack` 达到 Exit Code 0，成功生成 `build/fw_mc.bin`。

## 严格编码规范（c_cpp_coding_standard.md）

1. **单函数 $\le 50$ 行**：新增自研函数必须控制在 50 行内，复杂逻辑拆分 static 辅助函数。
2. **入参 $\le 4$ 个**：函数参数严禁超过 4 个，多参封装为配置结构体指针。
3. **存量代码最小预算（Minimal Diff Budget）**：对 Marlin 和原厂库的修改必须保持最小修改范围，严禁大范围重构。
4. **内存与指针安全**：零动态堆内存分配（严禁 malloc/free/new/delete），数组下标替代指针黑魔法，禁用异常与 RTTI。
5. **硬件操作防御**：卫语句优先，硬件轮询必须带超时退出。

## 交付物与验收标准

1. `mcu-p3` 源码变更：USART2 接收 MiniMCProto 帧并在收到版本查询时准确回传应答帧。
2. 构建产物：`mcu-p3/motion-controller-mcu/build/fw_mc.bin` 成功生成并注入 trailer。
3. 过程审计凭据：在 `project-control/docs/evidence/mc_firmware/MCQ-0105/runs/run_20261027_01/result.md` 记录完整的 Pre-Check、代码 Diff、编译日志、函数行数审计。
