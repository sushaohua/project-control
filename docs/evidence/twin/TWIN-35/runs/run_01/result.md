## 2. 端到端功能闭环测试

### 2.1 实时遥测与界面初态
- 访问 `http://192.168.77.134:8080/index.html`：
  - 顶栏连接指示灯即时变绿显示【已连接】，世代号 `GEN: 550`；
  - 顶栏实时显示喷嘴温度 `122.3 °C`、热床温度 `24.5 °C`；
  - 默认首屏呈现【🖨️ 打印工作台】，包含 SVG 进度环、用时/剩余时间统计卡片、当前 G-code 指令行流式面板；
  - 右侧呈现 3 款内置免切片样例模型（`🚢 3DBenchy.gcode`、`📦 CalibrationCube.gcode`、`🎨 ColorSwatch_4Color.gcode`）及拖拽上传区。

### 2.2 作业生命周期闭环 (`/api/v1/jobs/*`)
- **选择与启动**：点击 `🚢 3DBenchy.gcode` 卡片【一键载入】-> 点击【▶ 开始打印】：
  - 后端响应 `{"status":"ok","message":"Job started"}`；
  - 状态转为 `PRINTING`，进度环与百分比动态递增（0.5% -> 2.5%）；
  - G-code 流式指令框平滑刷新当前运动指令（例如 `G1 X55.96 Y79.40 Z0.20 E0.10 F3600`）；
  - **选项 A 安全硬门禁核查**：`heater_duty_percent` 恒定为 `0%`，绝对零强电发热。
- **暂停与继续**：
  - 点击【⏸ 暂停】-> 状态转为 `PAUSED`，G-code 停留在当前行；
  - 点击【▶ 继续】-> 状态恢复 `PRINTING`，继续增量执行。
- **取消作业**：
  - 点击【⏹ 取消作业】-> 状态平稳回归 `IDLE`，进度归零。

### 2.3 手动运控与 5×5 自动调平 (`/api/v1/motion/*`, `/api/v1/leveling/*`)
- 切换到【🕹️ 轴控与调平】Tab：
  - **步进微调**：点击步长切换档位（0.1 / 1 / 10 / 100 mm）；
  - **XY 触控罗盘**：点击 `▲ +Y`、`◀ -X`、`+X ▶`、`▼ -Y`，实时坐标读数板毫厘级刷新；
  - **Z 轴微调**：点击 `+0.05` / `-0.05` 婴儿步微调，Z 坐标平滑响应；
  - **一键全轴归零**：点击【🏠 全部归零 (G28)】，X/Y/Z 读数准确回零 (`0.00 mm`)；
  - **5×5 调平高程偏差热力图**：
    - 25 点网格单元格渲染完成，颜色自负偏差深蓝 (-0.08mm) 经平整翠绿 (0.00mm) 至正偏差警戒红 (+0.21mm)；
    - 极值跨度显示 `0.29 mm`，平面倾斜特征显示 `X-偏高 / Y+偏低`。

### 2.4 E-STOP 紧急急停互锁防线 (`/api/v1/emergency/*`)
- 点击顶栏常驻【🛑 E-STOP 急停】按钮：
  - 界面立即弹出全屏红色急停报警模态框；
  - 后端注入 `M112` 指令，状态切为 `ESTOP_FAULT`；
  - 再次尝试点击 Jog 移动或开始作业，全部被硬性拦截并拒绝。
