## 验收与交付

逐项覆盖正常转发、MC 正常而 SCM 不回复、SCM 独立恢复、旧回复/未知状态及不支持项；每项有触发、输入、预期、期限来源和禁止误报。真实采集、源码推导、受限模型假设分别标明。ARCH 与相关实现岗位独立评审；不能等 MS-14 跑通才定义正确答案。

交付：独立从控样例、故障/恢复预期、期限来源及评审记录。运行卡附实际命令、退出结果、日志、版本组合与制品摘要；文档卡附准确文档版本与来源/评审。候选 commit、diff、合入版本只在适用且实际产生后填写。向登记的 COORD 交位置并取得回执；共同行为见 [[AI_SoC_协作方案/templates/角色任务提示词|交付格式]]。
