# SoC 温度遥测模拟屏幕

浏览器交互原型。直接用浏览器打开 [index.html](index.html)，无需安装依赖或启动服务。样式与脚本使用同目录文件，请保留这三个文件的相对位置。

用户已选择浏览器交互原型。界面以待接受的 SoC 温度多模块架构为参考，模拟 STATE 向屏幕提供双端温度快照。当前不读取实际程序、串口、D-Bus、DDS 或网络。

支持正常采样、TH 数据过期、TH 传感器故障、链路断开、AP 进程重启五种场景，以及暂停/继续模拟采样。重启会清空旧快照；失联和过期明确显示上次有效值；故障显示无效值而不是 0°C。趋势图仅画有效样本。

1 Hz、3 秒陈旧期限、重启等待 1.5 秒和温度曲线均为界面演示参数，不是已批准的产品参数。模拟传感器状态不证明硬件故障检测能力。加热硬件未接入，无加热或运动操作。本原型不能用于硬件验收。

后续由 UI/STATE Owner 接受快照 API 后，替换本地模拟数据源；屏幕只消费公开状态接口，不直接访问 UART。D-Bus/DDS 的进程与版本选型由正式契约决定。
