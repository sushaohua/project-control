# MS-04 核查真实 MC 双向串口与实收样例

## 目标

在固件接口可用条件成立后，用独立只读客户端验证 Ubuntu USB 直通 MC 的请求/应答，交出原始 TX/RX。

## 输入与写入边界

MS-03 允许的探测、MS-02 固件身份，以及 TASK-005 的 MCQ 接口验收或等效现成接口证据。COM8 是 Windows 标识，当前 Ubuntu 使用经核验的 /dev/ttyUSB0；缺接口先登记，不改固件或用日志冒充响应。

建议路径：`tests/hil/mc-query/**；本任务独立日志目录`。逻辑目录不是授权，派单时映射真实仓库、工作区、文件白名单及证据位置。读取 B0、本卡与相关已接受输入；参考报告只作线索。

## 验收与交付

记录实际监听端点、Marlin 输入/输出通道和查询 TX/RX。证明可以收到固件回复，连接成功本身不算通过。确需桥接改动时另列准确范围并评审，当前核查任务不顺手改源代码。 样例注明实际命令、源码/配置版本和完整字节；提供 MS-05 所需的版本/温度实收行为，异常不能归一成成功。

交付：实际双向端点、带版本的原始 TX/RX 与实收回复样例。运行卡附实际命令、退出结果、日志、版本组合与制品摘要；文档卡附准确文档版本与来源/评审。候选 commit、diff、合入版本只在适用且实际产生后填写。向登记的 COORD 交位置并取得回执；共同行为见 [[AI_SoC_协作方案/templates/角色任务提示词|交付格式]]。
