### 1.2 吸收 `mcu-p3` 核心编码门禁规则（2026-10-26 深度固化）
应用户明确指令，已将来自 `/home/sushaohua/agents/mcu-p3/AGENTS.md` 及其细分规则体系（`c_cpp_coding_standard.md`、`api_modular_design.md`）的核心硬门禁全量吸收至全工作区：
1. **【硬性门禁 1】严禁编写超 50 行的自研非结构体函数**：单个函数必须控制在 50 行以内，复杂逻辑必须按阶段拆解为带 `static` 修饰的内部小步辅助函数；
2. **【硬性门禁 2】严禁编写超 4 个入参的自研非结构体函数**：自研函数入参严禁超过 4 个，超额参数必须封装为专用结构体指针传入（如 `const config_t*`、`context_t*`）；
3. **存量继承代码豁免原则（Minimal Diff Budget）**：自研新增代码 100% 严格执行上述门禁；第三方开源或移植存量代码（如 Marlin 运动控制器、系统库）以最小修改预算优先，严禁大范围无关重构或破坏既有外部 ABI；若冻结 ABI 需兼容历史多参入口，公共包装函数必须将实现拆解委托给符合 $\le 50$ 行且 $\le 4$ 参的静态辅助函数；
4. **内存与指针安全**：
   - 指针显式化，严禁 `*dst++ = *src++` 等压缩指针黑魔法，统一使用数组下标或分步拆行递增；
   - 严禁超过二级的多重指针（禁止 `***ptr`），指针解引用与取地址操作必须独立成行；
   - 裸机与嵌入式 C++ 零动态堆内存分配（严禁 `new`、`delete`、`malloc`、`free` 及动态 STL 容器）；
   - 禁用异常体系与 RTTI（`-fno-exceptions -fno-rtti`），显式两阶段初始化，编译期 `static_assert` 结构体布局校验；
5. **控制流与接口防御**：
   - 函数入参在前、出参在后，只读入参必须加 `const`；
   - 对外公开函数入口第一行必须进行防御性空指针校验（Guard Clause），非法指针立即返回错误码；
   - 状态返回值统一度量（强类型错误码或 `bool`），业务数据统一通过末尾出参传出；
   - 卫语句优先，函数嵌套严禁超过 3 层；禁用嵌套三元运算符；复合逻辑条件拆解为具名临时布尔变量；
6. **硬件与外设操作安全**：
   - 寄存器读-改-写分步执行（Clear 后 Set），严禁单行合并清除与置位；
   - 硬件轮询等待强制超时保护（严禁 `while (!FLAG);` 空死等循环，必须展开带超时计数器退出）；
   - 严禁硬编码数值与魔数，位操作统一使用显式移位（`(1U << bit)`）或标准库位掩码宏。
