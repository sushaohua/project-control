## 2. 核心技术细节与技术债务消减记录

### 2.1 AP 宿主端健壮性治理 (`soc-ap`)
1. **波特率校验消减静默降级风险 (F03)**：在 `serial_posix.cpp` 中严格校验 Linux termios 支持的波特率常量，非法波特率立即报错退出，消除将 921600 等高速配置静默回退为 115200 的缺陷。
2. **写超时消减 CPU 忙等 (F04)**：将 `serial_write` 改造为带 1000ms 截止时间的 `poll(POLLOUT)` 驱动，有界等待并安全排空输出队列。
3. **四层严格校验引擎与确定性退出码**：
   - Layer 1（帧物理层）：校验 SOF (`0x55 0xAA`) 及 CRC-16-CCITT；
   - Layer 2（协议标志层）：校验 `flags & IS_RESPONSE`，识别回环与广播欺骗；
   - Layer 3（事务关联层）：校验 `src_id == target_id`、`dst_id == AP`、`seq == req_seq`，消除跨设备与跨事务错位；
   - Layer 4（业务语义层）：校验 Payload 长度边界与协议命令，检测 `CMD_NACK` 明确失败；
   - 确定性退出码：`0` (SUCCESS)、`1` (TIMEOUT)、`2` (CORRELATION_ERR)、`3` (IO_ERROR)、`4` (USAGE_ERROR)。

### 2.2 MC 运动控制器端透明路由与中断解耦 (`mcu-p3/motion-controller-mcu`)
1. **移除伪造 TH 身份与死锁风险 (F08, F09)**：彻底移除在 `USART2` IRQ 回调中向 TH 发送 `M115` 文本并伪造 `src_id=0x03` 的阻塞轮询代码，恢复 MC 中继纯粹透明性。
2. **双向原生中继转发 (F11)**：
   - AP $\to$ MC $\to$ TH：检测 `dst_id == 0x03`，递减 `hop_limit`（防环保护），置位 `route_ctrl |= 0x04`，重算 CRC，通过 USART6 发往 TH；
   - TH $\to$ MC $\to$ AP：检测 `dst_id == 0x01`，执行相同递减与置位，通过 USART2 原样回传 AP。
3. **中断与业务完全解耦 (F10)**：
   - `gui_rx_callback`（USART2 IDLE IRQ）仅耗时 $< 2\mu s$ 执行环形队列推入并重置 DMA；
   - 主循环 `main.c` 周期调用 `minimc_proto_poll()`，在主线程上下文中安全处理帧分发与超时。
4. **升级模式独占总线保护 (F22)**：
   - 在 `wk_usart.c` 的 `forward_uart_send_raw` 中增加 `s_forward_mode == FORWARD_UART_MODE_UPGRADE` 拦截，杜绝正常查询报文干扰固件升级。

### 2.3 TH 工具头端原生协议栈与文本/二进制流分流 (`mcu-p3/color-engine-mcu`)
1. **TH 原生自报真实固件身份**：
   - `GET_VERSION` (0x01) 回复 16 字节 `CMD_VERSION_REPORT` (0x02)，携带真实 `proto_ver=2.0`、`firmware_ver=1.0`、`boot_id=0x8877AA55`、`git_commit=0x6356C05A`、`capabilities=7`；
   - `PING` (0x03) 回复 12 字节 `CMD_PONG` (0x04)，回显 `t_originate_ms`，上报 `planner_buf_free=0`、`rx_fifo_free_units=4`；
   - 产出报文与独立黄金帧逐字节 100% 匹配。
2. **USART1 接收分流解耦**：
   - `minimc_proto_poll()` 流式消费 DMA 环形缓冲区；
   - 遇到 `0x55 0xAA` 序列进入二进制状态机解析并校验 CRC；
   - 非二进制字符透明推入 `s_text_ring`（512 字节环形缓冲区）；
   - `USART1_has_byte()` 与 `USART1_get_byte()` 无阻塞消费 `s_text_ring`，原有运动控制与温控 G-code 解析逻辑零侵入、零污染。
3. **带超时保护的二进制发送**：
   - `usart1_send_raw` 在所有硬件等待阶段均配备 500,000 次轮询递减超时保护，杜绝死等挂死。
