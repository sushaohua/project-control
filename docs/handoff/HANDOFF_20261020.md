## 源码核验结果

1. USART2 IDLE 中断仍调用 `gui_rx_callback()`，DMA 复用 GUI `rx_fifo`，DGUS 仍使用 USART2 TX；迁移 AP 通道需覆盖收、发及解析，不能仅改初始化。
2. MC M115 分支仍在 `#if 0` 内；M105 有实现，但 printf 经 USART1 输出，不是 AP USART2 请求/应答闭环。
3. MC 正常 TH 回传消费仍为 `filaout`；USART1 `T` 触发 500 轮 `G4 P0` / `ok2` 测时只覆盖 MC↔TH，未运行，不能当 AP 全链路 RTT。
4. MC App 本地 build 目录不存在。TH 有既有 BIN、ELF、Anchor、版本头；内部 SHA/CRC/Anchor 一致，但当前源码到二进制对应关系、板上身份未验证。TH 打包工具已剥离已有合法 Trailer，不应误报为必然重复追加；原始/发布 BIN 共名仍应在验收时区分。
5. Bootloader 两目录均只有 ELF/BIN/HEX/MAP，无法据此复现源构建。MC CMake 有一个不存在的 include 目录引用 `project/marlin/marlin_gcode`，尚不能认定它导致构建失败。
6. 当前 ARM GCC 9.2.1、CMake 3.16.3、Make 4.2.1、Ninja 1.10.0 存在；没有执行 MCU 构建。隔离输出候选命令已写入登记 §6，供 MS-02 使用。
