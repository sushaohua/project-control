## 2. 现场技术缺陷消除与代码改进记录

在真实硬件台架联调期间，排查并清零了 4 项关键缺陷，全部修改遵循代码规范并通过了独立 QA 复验：

1. **宿主机 ModemManager 串口独占死锁 (ETIMEDOUT -110)**:
   - *根因*: Ubuntu 默认后台服务 ModemManager 向 CH340 发送 AT 探针指令导致串口锁死。
   - *处置*: 永久停用 ModemManager (`systemctl disable ModemManager`) 并重新绑定 USB 接口。
2. **TH 从控 Bootloader 扇区 127 签名锚点缺失**:
   - *根因*: AT32F423 Bootloader 在启动时强校验 Sector 127 (`0x0803F800`) 的 140B Anchor；历史升级残留导致校验失败停留在 Bootloader。
   - *处置*: 使用 [`pack_firmware.py`](file:///home/sushaohua/workspace/ai_soc_project/mcu-p3/motion-controller-mcu/tools/pack_firmware.py) 生成有效 Anchor 刷入 `0x0803F800`，恢复正常跳转至 App (`0x08004000`)。
3. **MC DMA 中断标志丢失与接收轮询丢包**:
   - *根因*: `USART6_IRQHandler` 触发 DMA 接收完成时设置了 `forward_uart_rx_complete` 标志，但上层轮询函数未检查该标志。
   - *处置*: 在 `forward_uart_rx_poll()` 入口增加标志判断，杜绝 TH 响应帧丢弃。
4. **Marlin 存量文本轮询吞帧竞态**:
   - *根因*: `motherboard.c` 周期轮询读取 USART6 匹配文本，截断剥除了 `0x55 0xAA` 协议二进制帧。
   - *处置*: 抽象拆分出专用的二进制流安全读取接口 `forward_uart_proto_rx_read()`，实现协议流与外设文本流的物理级解耦。
