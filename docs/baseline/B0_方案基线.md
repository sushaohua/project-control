## 当前执行约束

- 对接约定先于依赖它的实现；调查/设计可产出尚不存在的接口，不等整个产品冻结。
- 主控查询优先用真实 Marlin 固件。主线直接对接真实硬件，不再为模拟环境开发专门的适配层。
- 模拟仅保留无硬件环境下的轻量 Python Mock，作为离线单测辅助，不作为里程碑准入门槛。
- MC-only 与 MC+TH（原 SCM）物理结果分别验收（出口 A 与 出口 B）。
- MC/TH 定制逻辑优先复用；Mock 仅为离线测试。真实查询、物理动作和未来目标 SoC 运行分别记录证据。
- 已有接口够用时，真实只读测试可按实际条件开展，不一律要求先改 MCU；涉及生产代码与安全/硬件仍需相应负责人和授权。
- 模块分析、竞品、旧 AI 输出都只作参考；[[nextgen_3dprinter_ap_software_whitepaper_20261005_174400]] 明确为临时输入，不进入正式基线。
- 四类主流还可有握手/回应、配置、诊断、升级、时间与视频会话控制等支撑流；不要求首版全部实现。文件存储介质、DDS/D-Bus/MQTT 映射和能力须按本机输入核对。
- 任务卡为权威明细，COORD 唯一写正式状态。实际认领与证据以细卡为准；TASK-001～018 是工作包，不直接派单。迁移控制仓前保持单一权威入口。
