## 1. 交互设计系统规范 (Design Tokens & Human Factors)

### 1.1 触控与人体工程学标准
- **最小触控热区 (Touch Target)**：所有交互按钮、可点击卡片、开关滑块的有效点击区域严格满足 **$\ge 48 \times 48\text{ px}$**，触控间距 $\ge 8\text{ px}$，满足 7寸/10寸 工控触摸屏盲操容错。
- **两击直达原则 (Two-Click Access)**：急停、暂停、开始打印、调平触发、换料确认等核心业务操作必须在 2 次点击以内完成。
- **全局一击急停 (One-Click E-STOP)**：红色 E-STOP 紧急急停常驻顶栏最右侧，无论处于哪个标签页均 1 击瞬时熔断。

## 2. 全局常驻顶栏交互规范 (Global Header)

```
+---------------------------------------------------------------------------------------------------+
| 🖨️ AI-SoC 3D HMI   [● Connected] [GEN: 550]   🔥喷嘴: 122.3°C  🛏️热床: 24.5°C   🛑 E-STOP   🔔(0) ⚙️ |
+---------------------------------------------------------------------------------------------------+
```

### 2.1 组件明细与状态交互
1. **品牌与运行模式 (`.brand-group`)**：
   - 包含主 Logo `🖨️`、标题 `AI-SoC 3D HMI`、环境副标 `VMware Twin · Option A 纯逻辑空跑`。
2. **连接与版本世代 (`#conn-pill`, `#state-gen`)**：
   - 绿灯（Connected，SSE 心跳 $< 3\text{s}$）；黄灯（Reconnecting，断线重连中）；红灯（Disconnected，超时断联）。
3. **全局常驻温度胶囊 (`#header-th-pill`, `#header-mc-pill`)**：
   - 喷嘴胶囊：`🔥 喷嘴: 122.3 °C`；热床胶囊：`🛏️ 热床: 24.5 °C`；
   - 点击温度胶囊：页面平滑跳转至“温度与传感器”标签页并高亮温控卡片。
4. **全局红色紧急急停大按钮 (`#header-estop-btn`) —— 核心安全控制点**：
   - 视觉样式：红底白字带警示斜纹，尺寸 $\ge 120 \times 44\text{ px}$，字重 Bold；
   - 交互时序：用户单击即刻通过 REST 发起 `POST /api/v1/jobs/cancel?reason=estop` 并弹出特权复位解锁弹窗；
   - 状态分支：
     - 正常运行态：红色可点击；
     - 急停熔断生效态：脉冲剧烈闪烁，文字变为 `🛑 已急停自锁`，整机走线硬拒绝。
5. **HMS 告警抽屉入口 (`#header-hms-bell`)**：
   - 铃铛图标带红色圆点计数（未处理告警数）。点击从视窗右侧平滑滑出 HMS 告警抽屉（宽度 $360\text{px}$）。

## 3. 核心主标签页 1：🖨️ 打印工作台 (Print Dashboard & Jobs)

作为默认主首页，提供左右双栏响应式网格布局（宽屏 $1:1$ 或 $6:4$ 栅格，窄屏上下堆叠）。

### 3.1 左栏：实时打印状态与流式走线看板

```
+-------------------------------------------------------+
| 状态: [ PRINTING 正在打印 ]        强电 0% 锁定 (Safe) |
|                                                       |
|                  .---.                                |
|                /   68% \     Layer 128 / 350          |
|               |    进度 |    已用: 00:24:12           |
|                \       /     剩余: 00:11:05           |
|                  '---'                                |
|                                                       |
| 当前模型: 3DBenchy_multi_cmyk.gcode                   |
| 正在执行: G1 X124.50 Y88.20 Z0.20 E1.85 F3600 (L1420)  |
|                                                       |
| [ ▶ 开始打印 ]   [ ⏸ 暂停 ]   [ ▶ 继续 ]   [ ⏹ 取消 ] |
+-------------------------------------------------------+
```

1. **状态大徽标 (`#job-status-badge`)**：
   - `IDLE` (空闲就绪，灰/蓝)；
   - `PREPARING` (准备自检，黄色闪烁)；
   - `HOMING` (G28 回零中，青色流光)；
   - `PRINTING` (流式走线中，绿色呼吸)；
   - `PAUSED` (安全挂起/断料，橙黄警示)；
   - `COMPLETED` (打印完成，绿色常亮)；
   - `ESTOP_FAULT` (急停故障，赤红警报)。
2. **大环形进度可视化 (`#job-progress-circle`)**：
   - SVG 圆环动态进度条，直径 $160\text{px}$，线宽 $12\text{px}$，平滑过渡（`transition: stroke-dashoffset 0.5s ease`）；
   - 圆环中心显示大字号完成度百分比（如 `68.5%`）；
   - 下方紧随当前层数卡片：`Layer 128 / 350`；
   - 时间卡片：已用时间倒计时（`已用 00:24:12`）与估算剩余时间（`剩余 00:11:05`）。
3. **流式 G-code 指令动态监视器 (`#job-stream-box`)**：
   - 等宽字体代码框，显示当前正在执行的 G-code 指令行号与内容：
     `L1420: G1 X124.50 Y88.20 Z0.20 E1.85 F3600`；
   - 绿色常驻徽标提示：`🛡️ Option A 纯逻辑走线中 · 强电输出锁死为 0%`。
4. **打印操作控制按钮组 (`.job-control-actions`)**：
   - `[ ▶ 开始打印 ]` (`#btn-job-start`)：空闲态可用，点击发起 `POST /api/v1/jobs/start`；
   - `[ ⏸ 暂停打印 ]` (`#btn-job-pause`)：打印中可用，点击发起 `POST /api/v1/jobs/pause`；
   - `[ ▶ 继续打印 ]` (`#btn-job-resume`)：暂停中可用，点击发起 `POST /api/v1/jobs/resume`；
   - `[ ⏹ 取消打印 ]` (`#btn-job-cancel`)：打印中/暂停中可用，点击弹出二级确认确认后取消。

## 4. 核心主标签页 2：🕹️ 轴控与调平 (Motion Control & Bed Leveling)

为打印前准备、对焦点校准与热床调平设计，双栏布局：

### 4.1 左栏：CoreXY 三轴手动控制罗盘 (Motion Jogger)

```
+-------------------------------------------------------+
| 步长切换: [ 0.1mm ]  [ 1mm ]  [ 10mm* ]  [ 100mm ]    |
|                                                       |
|                   [ +Y 前进 ]                         |
|         [ -X 左 ]  [ 🏠XY归零 ]  [ +X 右 ]             |
|                   [ -Y 后退 ]                         |
|                                                       |
| Z轴控制:   [ ⬆ Z上升 ]    [ ⬇ Z下降 ]                  |
| 婴儿步微调: [ +0.05mm ]    [ -0.05mm ]                 |
|                                                       |
| 实时微米坐标:                                         |
| X: 125.00 mm   Y: 88.50 mm   Z: 0.20 mm   E: 14.50 mm |
|                                                       |
| 归零控制: [ 🏠 全部归零 (G28) ]  [ 归零X ] [ 归零Y ]    |
+-------------------------------------------------------+
```

1. **步长选择器 (`#jog-step-selector`)**：
   - 单选按钮群：`0.1mm`（精细对焦）、`1mm`、`10mm`（默认选中）、`100mm`（长距移动）。
2. **X/Y 四向触控罗盘 (`#jog-pad-xy`)**：
   - 四向箭头按钮，每次点击向 `POST /api/v1/motion/jog` 发送相对步进；
   - 中心圆形按钮：`🏠 XY 回零`。
3. **Z 轴升降与婴儿步微调 (`#jog-pad-z`)**：
   - `⬆ Z 上升`（抬高喷头/下降热床）、`⬇ Z 下降`；
   - 专属 `0.05mm` 婴儿步微调按钮（首层压制调平必备）。
4. **实时坐标高精数字屏 (`#coord-display-board`)**：
   - 同步呈现底层 MC 0x16 报文上报的微米换算坐标，保留 2 位小数（毫米）。
5. **一键全归零 (`#btn-home-all`)**：
   - 触发 `G28`，启动 X/Y/Z 依次寻道归零，按钮呈现 Loading 旋转态直至归零完成标志位闭环。

### 4.2 右栏：5×5 自动调平网格彩色高程热力图 (Leveling Heatmap)

```
+-------------------------------------------------------+
| 5×5 自动调平高程偏差热力图 (单位: mm)                  |
|                                                       |
|   +0.05   +0.02   -0.01   -0.04   -0.08               |
|   +0.08   +0.03    0.00   -0.02   -0.05               |
|   +0.12   +0.05   +0.01   -0.01   -0.03               |
|   +0.15   +0.09   +0.04   +0.01    0.00               |
|   +0.21   +0.14   +0.08   +0.03   +0.02               |
|                                                       |
| 色标: [-0.20mm 深蓝] --- [0.00mm 翠绿] --- [+0.20mm 橙红]
| 极值差: 0.29mm   倾斜: X-偏高 / Y+偏低   RMS: 0.042mm |
|                                                       |
| [ 📐 重新触发 5×5 自动调平网格校准 ]                   |
+-------------------------------------------------------+
```

1. **25 点彩色矩阵热力图网格 (`#leveling-mesh-grid`)**：
   - 采用 5×5 CSS Grid 渲染，每个单元格展示该点实测高程偏差（如 `+0.05`）；
   - 动态背景着色算法：
     - 高程差接近 $0.00\text{mm}$（$\pm 0.02$）：翠绿色背景（`#10b981`）；
     - 高程过高（$> +0.05\text{mm}$ 至 $+0.20\text{mm}$）：橙黄色至赤红色渐变；
     - 高程过低（$< -0.05\text{mm}$ 至 $-0.20\text{mm}$）：浅青色至深蓝色渐变。
2. **高程平整度统计指标 (`#leveling-metrics`)**：
   - 最大偏差值（Max Variance）、极值高程跨度（Peak-to-Valley）、倾斜方向诊断（Tilt）。
3. **重新调平触发按钮 (`#btn-trigger-leveling`)**：
   - 点击向后端下发探针测量指令，网格单元格依次呈现闪烁测量动效。

## 5. 核心主标签页 3：🎨 供料与调色板 (Filament & Color Mixing)

1. **4 通道线盘卡片 (`.spool-card`)**：
   - Slot 1~4 立体线盘，支持配置颜色（C/M/Y/K）与材料类型（PLA/PETG/ABS）；

   - 4 条通道滑动输入条，总和强制恒定为 $10000$ 权重；
   - 实时混合色样本 Swatch（根据 4 色比例计算出的真实预览色样）。

## 7. 异常模态弹窗与安全交互时序 (Safety Modals)

### 7.1 断料安全暂停弹窗 (`#modal-filament-runout`)
- **触发源**：TH 光电传感器触发中断上报 `HMS 0x3001`；
- **界面行为**：主界面即刻弹出不可遮蔽的告警浮层，背景半透明暗化（`backdrop-filter: blur(4px)`）；
- **操作指引**：明确指引用户抽出残料、插入新耗材并点击 `[ 换料完成，恢复打印 ]`。

### 7.2 紧急急停特权复位弹窗 (`#modal-estop-active`)
- **触发源**：单击顶栏红色 `🛑 E-STOP` 按钮或底层 M112 急停；
- **界面行为**：警示色全屏闪烁一次，弹出红色警报模态框；
- **解除规则**：强制要求用户勾选“我已确认机械现场安全”复选框，方可激活 `[ 清除急停并复位 ]` 按钮。
