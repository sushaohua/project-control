# Web HMI 人机交互与用户体验验收清单 (UX Audit Checklist)

> **使用说明：**  
> 本清单由 **`DES-UI`** 编制，供独立 QA 与集成工程师（INTEGRATOR）在后续 `TWIN-33`、`TWIN-34` 与 `TWIN-35` 验收时逐项核对。每一项必须在 VMware 孪生运行环境（`http://192.168.77.134:8080`）的浏览器中实测通过，方可签署 UX 验收合格。

---

## 1. 顶栏常驻状态与全局安全验收 (Global Safety & Header)

| 检查项编号 | 验收场景与标准 | 预期行为与判定准则 | 实测结果 (PASS/FAIL) |
| :---: | :--- | :--- | :---: |
| **UX-HDR-01** | **全局常驻温度显示** | 无论切换到哪个主标签页，顶栏均清晰展示喷嘴与热床实时温度，数值与传感器同步刷新。 | 待验收 |
| **UX-HDR-02** | **全局红色一击急停 (One-Click E-STOP)** | 顶栏右侧醒目常驻红色 E-STOP 按钮，触控热区 $\ge 120 \times 44\text{ px}$；在任何页面单击 1 击立即触发急停熔断，走线瞬时终止。 | 待验收 |
| **UX-HDR-03** | **通信心跳与状态机世代** | 顶栏指示点实时反映与 `ui_gateway` 的 SSE 连接状态（绿灯在线，红灯断线），GEN 单调递增呈现。 | 待验收 |
| **UX-HDR-04** | **HMS 全局告警抽屉** | 单击顶栏告警铃铛图标，右侧平滑滑出抽屉式 HMS 诊断面板，不阻塞底层主操作。 | 待验收 |

## 2. 🖨️ 打印工作台主航道验收 (Print Dashboard & Jobs)

| 检查项编号 | 验收场景与标准 | 预期行为与判定准则 | 实测结果 (PASS/FAIL) |
| :---: | :--- | :--- | :---: |
| **UX-JOB-01** | **首屏默认主航道直达** | 打开 Web 控制台默认激活【🖨️ 打印工作台】，无需用户二次找寻打印控制入口。 | 待验收 |
| **UX-JOB-02** | **外部 G-code 拖拽上传** | 将外部 `.gcode` 文件拖拽入拖拽区，界面呈现高亮反馈并平滑上传至网关落盘。 | 待验收 |
| **UX-JOB-03** | **内置经典测试模型一键载入** | 3DBenchy、CalibrationCube、ColorSwatch 三大内置模型卡片清晰可见，点击【一键载入】无需上传即可就绪。 | 待验收 |
| **UX-JOB-04** | **大环形进度与层高监控** | 打印执行中，环形进度条平滑旋转推进，实时显示百分比（0.0%~100.0%）与当前层/总层数。 | 待验收 |
| **UX-JOB-05** | **作业控制操作闭环** | 开始打印（IDLE可用）、暂停打印（PRINTING可用）、继续打印（PAUSED可用）、取消打印（带确认阻断）四态按键切换流畅无冲突。 | 待验收 |
| **UX-JOB-06** | **强电锁死安全标签呈现** | 页面醒目常驻绿色安全标：`Option A 纯逻辑空跑 · 强电 0% 锁死`，绝不出现虚假加热飞温提示。 | 待验收 |
| **UX-JOB-07** | **流式 G-code 指令行监视** | 实时等宽代码框准确显示当前执行的 G-code 指令行号与命令内容。 | 待验收 |

## 3. 🕹️ 轴控与调平网格验收 (Motion Control & Bed Leveling)

| 检查项编号 | 验收场景与标准 | 预期行为与判定准则 | 实测结果 (PASS/FAIL) |
| :---: | :--- | :--- | :---: |
| **UX-MOT-01** | **触控罗盘步长切换** | 0.1mm、1mm、10mm、100mm 单选切换灵敏，X/Y 四向微调与 Z 轴升降指令响应准确。 | 待验收 |
| **UX-MOT-02** | **婴儿步 (0.05mm) 微调** | 提供专属首层压制调平 0.05mm 升降按钮，防误触间隔明确。 | 待验收 |
| **UX-MOT-03** | **一键全局归零 (G28)** | 点击【全部归零 (G28)】按钮，按钮呈现旋转 Loading 状态，直至归零完成恢复。 | 待验收 |
| **UX-MOT-04** | **5×5 调平网格彩色热力图** | 25 点高程矩阵清晰渲染，基于平整度呈现绿/蓝/橙彩色渐变背景，显示极值跨度与 RMS 统计。 | 待验收 |
| **UX-MOT-05** | **触发自动调平标定** | 点击【重新触发 5×5 自动调平】按钮，调平单元格依次呈现测量动画。 | 待验收 |

## 5. 易用性与人机交互通用标准验收 (Human Factors & Usability)

| 检查项编号 | 验收场景与标准 | 预期行为与判定准则 | 实测结果 (PASS/FAIL) |
| :---: | :--- | :--- | :---: |
| **UX-GEN-01** | **触控热区达标 ($\ge 48\text{px}$)** | 核心按钮与触控罗盘几何尺寸均 $\ge 48 \times 48\text{ px}$，手指盲操无相邻误触。 | 待验收 |
| **UX-GEN-02** | **按键防抖保护 (Debounce)** | 快速连击开始/暂停/归零按钮时具备 $300\text{ms}$ 防抖保护，绝不向后端发送重复并发冲突请求。 | 待验收 |
| **UX-GEN-03** | **国际化双语免刷新切换** | 中英双语一键切换，所有新建组件文案均具备完整 `data-i18n` 字典覆盖。 | 待验收 |
| **UX-GEN-04** | **主题自由切换** | 深色（暗黑）、明亮浅色、赛博朋克三套主题切换自如，高对比度不刺眼。 | 待验收 |
| **UX-GEN-05** | **急停特权复位解锁** | 触发急停后，必须显式勾选安全确认复选框方可点击解除急停复位，防止意外带故障启动。 | 待验收 |
