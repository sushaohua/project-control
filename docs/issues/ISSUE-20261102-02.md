# ISSUE-20261102-02 任务拆解与执行跟踪

## 1. 背景与目标
用户明确要求：MC 的版本号在当前分支上用 2.0.1 来记录，MC 和 TH 当前保持一致。
历史由于 MiniMCProto v2.0 联调时在 `minimc_proto.c` 的 `build_version_resp()` 中顺手硬编码了 `out_buf[14] = 1U; out_buf[15] = 0U;`，导致无论外部如何配置版本，协议响应始终恒定返回 `1.0`。
本任务旨在将 MC 与 TH 版本号正式统一定义为 `2.0.1`，消除源码中的硬编码字面量，接入由 `version_tool.py` 生成的 `version_autogen.h` 真实宏，完成端到端对齐与构建验收。
