# 协议资料目录

用户取得的 AP-MC、MC-TH 协议草稿可直接放在本目录。支持 Markdown、PDF、Word、表格和配套帧样例；保留原文件，名称尽量带版本或日期，例如 `ap_mc_protocol_draft_v0_1_20261019.md`。后续版本用新文件保存，避免覆盖旧稿。

## 放入后怎样登记

在主对话发送文件名或完整路径，例如：

```text
协议已放入 project-control/docs/specs/文件名.pdf。
这是草稿，请读取、登记来源和版本，对照现有代码与串口配置检查差异。
可以确认的更新到项目输入，有冲突的向我提问。
```

AI 应在[通信输入文档](../baseline/ap_mc_th_comm_inputs_20261019_190400.md)中登记文件路径、来源、版本、用途、适用链路、核对结论及未决问题，并向用户报告具体保存位置。未取得的信息保留待确认。

本目录保存输入原稿和说明；草稿放入目录不表示已被接受为实现依据。正式可执行接口仍按[项目接口管理规则](../../.agents/rules/04_公共看板与读写协议.md)定位原件，本次不迁移或替换现有协议基线。

## 串口信息保存在哪里

当前接线、端口、波特率及确认状态统一维护在[串口链路登记](../baseline/serial_links.md)。用户可直接在对话提供信息，由 AI 写入登记；有变化时先保留变更依据，再核对集成清单与运行配置。源码默认值、基线登记和实物接线不得互相冒充。

尚未收到用户提到的新协议草稿；收到文件后再登记具体身份。
